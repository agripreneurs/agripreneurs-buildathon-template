# Hardware Schematics & Circuit Diagrams (`/hardware/schematics`)

Place your circuit diagrams, wiring photos, CAD models, and PCB layout files in this folder.

## Recommended Deliverables
1. **Circuit Diagram / Wiring Image:**
   - Export an image (`circuit_diagram.png` or `.pdf`) created using Fritzing, KiCad, EasyEDA, or hand-drawn schematics clearly showing:
     - Microcontroller board pins used (GPIO, ADC, I2C, SPI, UART).
     - Sensors & actuator connections.
     - Power regulation (voltage dividers, buck converters, batteries).
2. **CAD / Enclosure Files (Optional):**
   - If you 3D printed a weatherproof enclosure or custom casing, attach `.stl` or `.step` files here.
3. **Field Photos:**
   - Include photos of the assembled prototype or breadboard setup.
